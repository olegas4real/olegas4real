### Como eu trabalho com agentes

Todo repositório meu tem um `AGENTS.md` como fonte única: o que o projeto é, os
comandos de verificação, as regras que não se negociam, um checklist de pronto e
as armadilhas já conhecidas. O `CLAUDE.md` só o importa, para não existirem duas
verdades divergindo em silêncio.

A ideia é simples: a defesa de um projeto não pode depender de alguém lembrar de
revisar. Tem que ser automática, e tem que estar escrita.
